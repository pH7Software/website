Hi guys!

Today I'm so glad to announce the release of <strong>pH7CMS 6.0, WoW</strong>.
<h3>What's in pH7CMS 6? - Changelog:</h3>
<ul>
   <li>The headline on the payment module wasn't aligned.</li>
   <li>You can now hide the users from the guest homepage (on the splash dating homepage and the classic homepage).</li>
   <li>You now have the possibility to set the "Sign-in Profile Image" field "mandatory".</li>
   <li>A new "<strong>Social Cartoon</strong>" template has been added! You will be able to enable it from your Admin Panel -&gt; Settings -&gt; Default Theme -&gt; "Cartoon"</li>
   <li>When a dark custom wallpaper was set on profile pages, the texts were difficult to read. Now fixed.</li>
   <li>A new module that give <strong>Similar Profiles</strong> on profile pages has been added.</li>
   <li>"Friend" feature is now separated into its own module. It now allows to<strong> disable the friend feature</strong> on profile pages (<strong>better for dating services</strong>).</li>
   <li>Holding Images for Profiles have been changed to some newer and much "modern"/"fashion" ones than before.</li>
   <li>Google Favicon Retriever now uses HTTPS so you won't have any errors if your website uses HTTPS protocol.</li>
   <li>The <a href="/adult-disclaimer-for-adult-dating-sites/">Adult Disclaimer</a> and the <a href="/ph7cms-comply-with-european-laws/">EU Cookie Consent Bar</a> can now work with HTTPS</li>
   <li>Other minor bug fixes have been fixed.</li>
   <li>pH7CMS 6.0 <strong>now requires PHP &gt;= 5.6</strong>. Please make sure your web host has PHP 5.6 or newer.</li>
   <li>Pagination constants have been added everywhere in the code to change easily the number of items per page.</li>
   <li>A LOT of improvements in the code, fix a bunch of legacy code, etc. These changes will make developers' life easier.</li>
   <li>Tidied up HTML files' indentation for nicer and cleaner code (for "note", "blog", "video" and "picture" modules).</li>
   <li>A few typos have been fixed.</li>
   <li>For people who don't have <a href="/get">pH7CMS Pro</a>, "Powered By" link in emails has been fixed and now visible.</li>
   <li>Better user input validation for "note" module (to avoid SEO spam from your users).</li>
   <li>With some web browsers, if a user ticked "Remember Me" checkbox, it wasn't possible to logout from the site. Now fixed.</li>
   <li>The IP Geolocation database has been updated.</li>
   <li>Registration and Profile Image forms were showing ugly valid/invalid icons in its fields. Now fixed.</li>
   <li>Fixed a few warnings triggered from PHP 7.1+ (<em>A non well formed numeric value encountered</em>).</li>
   <li>More PHP unit tests have been added to make pH7CMS even more stable and avoid future bugs.</li>
</ul>
<p>I really hope you will enjoy this new version!</p>
