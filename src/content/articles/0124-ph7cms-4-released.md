Hi folks!

Hope you are doing well today! 😉

In my case I got a really good news to announce you :) (that's the reason of this post 😁).

Yaaay! pH7CMS 4.0 has just been released (and available in your client area if you hold <a href="/startup-kit-social-business/">pH7CMS Pro</a>).

As you might noticed, since last year I'm now working on <a href="/ph7cms-the-best-powerful-tool-for-dating-business/">two/three weeks sprint</a> and for now one month, pH7CMS is now using a <a href="/new-versioning-system/">new versioning system</a> which make the development much more efficient.
<h3>So... What's the news in pH7CMS 4.0?</h3>
<ul>
  <li>Blue sub-menu of the profile page has been improved and is now nicer on mobile phones and tablets</li>
  <li>[Easier Registration] "State/Province" field has been removed from the registration page since it wasn't necessary and too annoying for new users</li>
  <li>Remove "team", "maintenance" and "help" static pages from the page module</li>
  <li>Possibility to disable "mail" and "instant messaging" modules through the admin panel</li>
  <li>Better explanation during the installation saying where is the <a href="/where-is-admin-panel-url/">admin panel URL</a></li>
  <li>Better interaction with the installation wizard</li>
  <li><strong>Love-Calculator</strong> module has been slightly re-designed</li>
  <li>Quick Search experience has been improved and now the default filters will be the previous ones searched</li>
<li>Search results weren't working when text filters were empty and containing blank spaces</li>
  <li>Bug fixed with some user profile searchable fields</li>
  <li>Unnecessary code has been removed from FrontController class (should be a little faster..)</li>
  <li>Other several minor improvements have been done</li>
</ul>
Again, I hope you appreciate my hard-work and if so <strong>please share</strong> this <strong><a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/" rel="noopener noreferrer">unique open source project</a></strong> with your friends, colleagues and online.

I really do my best to bring you the best social <strong>dating builder software</strong> ❤️

Have a lovely day!
