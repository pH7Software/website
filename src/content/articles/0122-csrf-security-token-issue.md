Hi guys!

Just a quick post for informing you a minor issue you might occur with your website.

The submission of the Settings form won't work if you enable the CSRF security token (disabled by default since <a href="/ph7cms-the-monster-is-ready/">pH7CMS 2.1</a>).

So please do not not manually enable the "CSRF security tokens" option (Admin -&gt; Settings -&gt; General -&gt; Security) until <a href="/working-hard-on-ph7cms-5/">pH7CMS 4.0.1 is released</a>.

Thanks for understanding and enjoy your dating website! :)
