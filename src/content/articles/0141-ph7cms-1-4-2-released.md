Hi guys!

Hope you are still doing well!

Today, I bring again a great news to you!

YESSSS, "pH7 Social Dating CMS" 1.4.2 is released and brings some very good improvements for YOU!

<h3>Below are the done tasks from the sprint backlog</h3>
<ul>
  <li>pH7CMS is now compatible with MySQL Strict Mode. From MySQL 5.7, the Strict Mode is enabled by default and so it was time to make pH7CMS compatible with those requirements. Users who had tried to install pH7CMS and got "pH7_settings table not found" error message won't have it anymore!</li>
  <li>Better text in the admin license manager</li>
  <li>Don't display the "Switch to pH7CMS pro" link in the admin sub-menu when the license is enabled</li>
  <li>Fixed CSS bugs when users were zooming in/out with the Web browser</li>
  <li>Special Upgrade script available for the <a href="/pro/">Pro license holders</a> (just create a ticket through your member area)</li>
  <li>Again another version made with lot of ♥️♥️♥️ for YOU (because we love what you do for your users!)</li>
</ul>

Enjoy, take care and have a wonderful week!

All the best!
Pierre
