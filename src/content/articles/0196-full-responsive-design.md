As you maybe know, we have stopped the development of the "mobile" module (for a while now) because it has become obsolete and it will be removed on the 1.2 (as you have probably seen on the announcement of the <a href="/hardworking-for-1-2-version-roadmap-overview">pH7CMS roadmap</a>).

We are currently working on a template 100% responsive and compatible on all modern devices (SmartPhone, iPhone, Android Phone, cellphone,  iPad, tablet, PC, laptop).
<p>The advantages of a site under a responsive design are:</p>

<ul>
  <li>The code is not duplicated.</li>
  <li>Maintenance is much easier</li>
  <li>Features are not restricted unlike "Mobile Version", which is a very basic version of the classic desktop website and users are often confused about it.</li>
</ul>
 

Mobile versions are therefore become obsolete since CSS3. Indeed, before CSS3, it wasn't possible to set up responsive designs because "media queries" weren't exist before. As pH7CMS wants always based on latest technologies, we decided to take this step! ;)

 

Finally, it will also increase your SEO/visibility. Indeed, mobile-friendly pages are more important than ever and <a href="http://googlewebmastercentral.blogspot.be/2014/11/helping-users-find-mobile-friendly-pages.html" rel="noopener noreferrer">Google has understood it</a> very well.
