Hi all!

Today I have again a very exciting new for you ;)

<strong>pH7CMS 6.0.13</strong> has just been released. This is a minor version with a few minor fixes and lot of code refactoring + PHP classes cleanup and minor DocBlock fixes.

It changes the look of some edit/delete/search buttons as well (making the design of your website nicer ;) ).

And the search system has been nicely improved into all modules currently available with pH7CMS. It also ignore any white spaces for easier search (this happens often when you copy/paste a world).

Finally, it fixes a remaining incompatibility with <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/issues/30" rel="noopener noreferrer">MySQL Strict Mode</a> (thanks <a href="https://github.com/chrisdpucci" rel="noopener noreferrer">Chris Pucci</a> for highlighting that issue).

You can download this new version of the CMS on <strong><a href="https://sourceforge.net/projects/ph7socialdating/" rel="noopener noreferrer">Sourceforge</a></strong> (or on <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS" rel="noopener noreferrer">Github</a>).

Hope you will LOVE it. And enjoy your Social Dating Web App thanks pH7CMS :)

<em>UPDATE: The installation steps (admin credential details and welcome email) have also been improved!</em>

Stay tuned and be with us! ;)
