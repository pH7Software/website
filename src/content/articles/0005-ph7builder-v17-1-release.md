<strong>pH7Builder, v17.1.0</strong> has just been released 🏆 This version is definitely <strong>a must-have for your social dating application</strong>! 💪

<h3><em>Release Summary 👀</em></h3>

✅ "<a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/pull/973" rel="noopener noreferrer">Chatroulette</a>" module has now been removed from the software (the module was too deprecated, but "chat rooms" remain present).

✅ RSS feed for comments wasn't working properly since v17.0.0.

✅ The Installation Wizard has been improved.

✅ YouTube API v3 has slightly changed and is now always required to retrieve YouTube Video details. The "Video" code has been changed to reflect those requirements from Google.

✅ Video Package is now also using PHP 7.1+ type declarations 🚀

✅ Forum Module: Rebranded "Forums" to "Discussions" board".

✅ File package is now throwing an Exception in case CURL fails.

✅ "unit test" file was always loaded when pH7Builder was installed with composer dev mode (in `autoload-dev`).

✅ Install `_install`'s dependencies when running the main composer.json <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/commit/6341e171563de5f961d045a84f314d3b7cc7c7c7" rel="noopener noreferrer">https://github.com/pH7Software/pH7-Social-Dating-CMS/commit/6341e171563de5f961d045a84f314d3b7cc7c7c7</a>

✅ Disabled by default `chatroulette` module.

✅ Refactoring "Cache" package from <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/tree/17.x/_protected/framework" rel="noopener noreferrer">pH7Framework</a>.
✅ Exclude a few other dev files from the distribution archive.

✅ This version offers several bug fixes, improvements, code refactoring, and enhancements. It also drops the support with PHP v5.6, v7.1, v7.2 and 7.3. Indeed, this new version now requires at least PHP v7. 🎉

✅ v17 introduced a <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/pull/949" rel="noopener noreferrer">CLI Installation Wizard</a> - Ideal for SaaS services, to automatically run a new pH7Builder instance in the background 👌

✅ After over 13 years of development, the project reached the 10,000 commits 🚀

✅ Muchly, Muchly more!

Enjoy your new social dating Web app, with pH7Builder v17 😍
