I regularly receive questions asking where is the admin panel login page (URL).

Although when the installation is finished it shows the URL and also present in the confirmation email, people might miss it if they install it with <a href="https://www.softaculous.com/apps/socialnetworking/pH7CMS" rel="noopener noreferrer">Softaculous</a>.

So, for those who are still looking for the <strong>admin panel</strong>, the URL by default (<a href="/doc/en/rename-the-admin-folder/">if not changed manually by you</a>) is "<em>http://your-website.com/<strong>admin123</strong></em>"

Hope this helps!
