Hi there!

We would like to announced that 1.0.XX branch is now abandoned and we will no longer released any official updates for free.
We're really sorry about that but we must do to move forward.

Indeed, we have preferred abandoned the development on 1.0.11 version to focus more seriously on branch 1.1.

But don't be sad!!! We will always publish the bugs and security updates to customers who request it.
If you need a current release or support, review the <a href="/get-started/">current pH7Builder options</a>.
