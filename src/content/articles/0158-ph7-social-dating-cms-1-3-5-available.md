Hi all!

Today I'm again pleased to announce the release of pH7CMS 1.3.5. As you may have noticed, since the end of December, we decided to go on "three-weeks" sprint release. This makes the development of <a href="/startup-kit-social-business/">pH7CMS and Tiers software</a> much efficient and faster.

<h4>So here is a brief summary of what has been done from the backlog</h4>
<ul>
  <li>Better support for the IPv6 (now you will be able to see full IPv6 address on all your users).</li>
  <li>CSS bugfixes and minor improvements on the design</li>
  <li>A couple of few minor bug fixes</li>
  <li>Bufix on Stripe payment provider (available only for <a href="/pro/">pH7CMS Pro holders</a>)</li>
<li>Security email texts have been rewritten + fixed on one wrong string variable in the login attempt protection emails (email sent when someone attempts to login to many times on an account <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/commit/a9b49d3271474fcc0395745fcf31fa1f1c29e802" rel="noopener noreferrer">git commit ref</a>)</li>
<li>And some other minor improvements</li>
</ul>
Again, please let me now if you have any suggestions about the software. And please note that you TOO, you CAN contribute to the project thanks its <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS" rel="noopener noreferrer">GitHub repo</a>.
