Hi ALL! :)

Really happy today saying that pH7Builder (or "pH7CMS" if you prefer ;) ) has been released!

It got a few improvements, AND a new module for "dating niche" (if chosen <a href="/ph7cms-ready-social-dating-niche/">during the installation</a>) or selectable through the admin panel later (Admin Panel -&gt; Mod -&gt; Enable/Disable Modules)
The module (called "Cool Profile Page") will make user profiles more "modern" and "dating-style" :)

In short, ideal for dating niches!
<h3>Brief Changelog:</h3>
<ul>
   <li>Added a new (dating) "User Profile Page" option.</li>
   <li>Refactoring; LOT, LOT, LOT of improvements in the code + better coding style.</li>
   <li>Display month in a textual format (such a Jan, Feb, Mar, etc.) on user "membership details" page (to avoid confusion with the date).</li>
   <li>Design improvements.</li>
   <li>Minor changes in "Installation Welcome Email" body.</li>
   <li><a href="https://github.com/php-fig/fig-standards/blob/master/accepted/PSR-2-coding-style-guide.md" rel="noopener noreferrer">PSR-2</a> fixes.</li>
   <li>Show how long a membership plan lasts (membership duration).</li>
   <li>Changed "Report" link text to a "Flag" icon.</li>
        <li>Added "Complexity" and "Case Sensitive" options for the CAPTCHAs.</li>
   <li>Redesigned user status icons (the "online", "away", "busy" and "offline" circles).</li>
   <li>Added lovely colour for "Flag" report icon and "Like" link.</li>
   <li>Renamed table names to lowercase only, and with "_" for separating words (to avoid issues if "lower_case_table_names" if enabled).</li>
   <li>Stored table names in class constants.</li>
</ul>
