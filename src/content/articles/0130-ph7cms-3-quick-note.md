Hi all!

pH7 Social Dating CMS 3 releases next Monday. It's mainly a maintenance version. Several bug fixes caused by <a href="/ph7cms-2-0-9-released/">pH7CMS 2.0.9</a> and <a href="/ph7cms-2-0-8-released/">pH7CMS 2.0.8</a>.

The version has also several design/CSS fixes for mobile phones and gets a new font (<em>Open Sans </em>font). The current font was looking a bit outdated and was never changed since pH7CMS version 1.2.

pH7CMS 3 (which is in fact pH7CMS, version 2.1.0) is also inaugurating the new <a href="/new-versioning-system/">versioning system</a>. So we had to start from a major version to initialzse it.

Hope you will enjoy it!

See you on Monday! Pierre ?
