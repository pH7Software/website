<p>Today I am pleased to announce that pH7CMS 1.1.8 is released.</p>
<p>This version is again more and more stable. You can also see a brief summary <a href="/about-ph7cms-1-1-8/">about pH7CMS 1.1.8</a></p>
<p>The version also included an important security fix. This vulnerability is present in all previous versions of pH7CMS. For security reason, we won't give more information about it on this public post. However, we can provide the "security bug fix" for customers (who bought a license) and explain what this security vulnerability can cause.</p>
<p>Nevertheless, we are very happy because our software remains one of the most secure findable on the Internet and it is only the second security vulnerability since the beginning of the construction of the CMS (almost three years ...!)</p>
<p>Again, we <strong>strongly recommend everyone to migrate their website to this new version!</strong></p>
