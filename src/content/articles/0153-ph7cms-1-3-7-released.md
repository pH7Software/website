Hi guys! Today I'm again very pleased to announce a great new pH7CMS version (plenty of nice improvements as usual :) ).
<h4>So, what's up in pH7CMS 1.3.7?</h4>
<ul>
  <li>New top menu for frontend and backend and specifically optimized for mobile devices with nicer style (iPhone, iPad, Android)</li>
  <li>New menu icons for better and nicer menu (on the first and second drop-down menu levels)</li>
  <li>Migrated Youtube API v2 to the new API v3 (for retrieving the video's data details)</li>
  <li>Updated old flag icons (for the UK and EU flags)</li>
  <li>Added social media sharing buttons for the Social Niche theme (choosable during the <a href="/ph7cms-ready-social-dating-niche/">Niche Section</a> in the installation wizard) and also activable in Admin Panel -&gt; Settings</li>
  <li>Adult disclaimer didn't work on other template than the "base". Now fixed</li>
  <li>Rewritten of <i>SettingFormProcess,</i> <i>MetaMainFormProcess</i> and <i>EditMembershipFormProcess</i> classes for DRY principle and again in order to get the best code!</li>
  <li>Bug fixed with email files when the template chosen was different than the "base" one</li>
  <li>Some other <em>nice</em> improvements</li>
  <li>On profile page, weight was displaying as height units. Thanks <a href="https://github.com/elimik31" rel="noopener noreferrer">elimik31</a> for his <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/pull/83" rel="noopener noreferrer">contribution</a> on <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS" rel="noopener noreferrer">pH7CMS's GitHub</a>!</li>
  <li>Several other minor bugs fixed</li>
</ul>

 

Again, I hope this new 1.3.7 version will make your life and your <a href="/startup-kit-social-business/">social business</a> easier and more profitable ;)
See you very soon for some other exciting posts, here on pH7CMS's blog!
