Anyway, today I have a wonderful news to bring to you!!! 🎉

<strong>pH7 Social Dating Builder 14.8.8</strong> has just been released!!! 🚀

This new version gives improvements, and few minor (CSS) fixes. The slideshow on the "classic" guest homepage has been fixed (there were a few design issues in there).

It also allows you to remove the "phone" and "address" fields for users (through Admin dashboard -&gt; User/Admin -&gt; Users -&gt; User Fields).

Finally, the default icon logos for "base", "zendate" and "cartoon" templates have been updated to nicer ones.

The full GitHub change log from <a href="/ph7cms-14-8-released/">v14.8</a> to this version can be found here: <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/compare/14.8.0...14.8.8" rel="noopener noreferrer">https://github.com/pH7Software/pH7-Social-Dating-CMS/compare/14.8.0...14.8.8</a>
