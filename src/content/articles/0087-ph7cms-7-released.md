Hi all!

Hope you are still doing great!

I'm very glad today to announce you the brand new version of "<em>pH7CMS, NaOH, 7.0.0</em>" 🏆🤗

This new versions got many code/speed improvements, improve the legacy code, fix a few major bugs with for example, "game" search form and Softaculous passwords (and fix several minor ones).
pH7CMS brings a few new features as well!

After the <a href="/preview-ph7cms-2/">Nudity Detector</a> added almost a year ago, pH7CMS 7 adds another great feature that allows you to know if the users' profile photos waiting for moderation approval aren't used on other dating websites by scammers.

Again, pH7CMS is the only and first social dating software to have a such feature that helps you to save a lot of time moderating your dating web app.

The UX and design haven't been improved in this version though it was the case in the few latest versions.

A new chat rooms provider has added, making now the Chat module compatible with https 💪

Hope you will enjoy the hard work put into pH7CMS for many years now :)
