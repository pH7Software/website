Hi folks! :)

Hope you are still doing great!

Today, I've amazing news for you! :) Indeed, pH7Builder (pH7CMS) got a new version (the v12.6.0!) 🎉

<h3>Overview of the Changelog:</h3>

<ol>
  <li>Several icons (gender icons, pending approval icon, none icon, RSS feed, and lot more!) have been replaced by new nicer ones.</li>
  <li>Each theme (template) has now a different icon which better represents the niche of each theme.</li>
  <li>[NEW FEATURE] Now, you can block a whole country very easily and surely in order to avoid spammers or unwanted users from countries the website don't target.</li>
  <li>The heart favicon has been replaced to a more "social" generic one (and not only "dating" style).</li>
  <li>More png/gif images have been replaced to SVG vector icons.</li>
 <li>Social icons (Facebook Connect, Twitter Connect, Google) have been replaced by much nicer/newer icons (more modern design).</li>
<li>Incorrect results when searching for males looking for males have been fixed (<a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/issues/202" rel="noopener noreferrer">#202</a>).</li>
<li>The GeoIp Database has been updated to its latest version.</li>
<li>Code refactoring and big improvements done in the code (developers will be happy!).</li>
</ol>

<p>
    In short, this <strong>v12.6</strong> version "mainly" improves and polishes the changes and features done in <a href="/ph7cms-10-released/">v10</a> and in <a href="/ph7cms-10-2-released/">v12.2</a>.
</p>

<p>I really hope you will appreciate the hard work I’ve done in the software! 😊</p>
