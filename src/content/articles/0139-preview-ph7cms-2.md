Hey guys! Hope you are still doing well and still enjoy well your <strong>pH7 Social Dating CMS 1.*</strong>!
If you are not a user yet... Just <a href="/get/">grab it for free</a> today ;)

Before you continue to discover <strong>pH7CMS 2.0, "H2O"</strong>, go <a href="/nominate-ph7cms-to-idate-awards/">nominate pH7CMS</a> to the iDate Awards 2017 (if not done yet ;) ).

Normally, this version would be the "1.4.4", but after long reflection and the huge major changes that pH7CMS got in its 36 previous versions already released. It makes more sense to be on the 2.* branch by now.

That's why, this version is 2.0.4 (instead of 1.4.4). And its version name is now "H2O" (successor of "p[H]").

So, pH7CMS 2.0.4 (the 37th version) got lot of improvements, is by far highly stable and secure.
<h3>Some of the nice features added to pH7CMS 2!</h3>
<ul>
  <li>The Splash Guest Page "base" template has been redesigned and has now several random background videos.</li>
  <li>New API version added for the Fake Profile Generator exclusively available in <a href="/startup-kit-social-business/">pH7CMS Pro Package</a>.</li>
  <li>Possibility to add the Google Maps API easily through the admin panel (<a href="http://googlegeodevelopers.blogspot.ie/2016/06/building-for-scale-updates-to-google.html" rel="noopener noreferrer">required by Google since June 22nd, 2016</a>).</li>
  <li>Improvements of the design.</li>
  <li>Better order of the fields in the installer.</li>
<li>Fix a few issues on modals when opened on small mobile devices (such as Report, Newsletter, Invite, Registration modals).</li>
  <li>A Smart "Nudity Detector" has been added so the moderation of the pictures added by your users will be much easier if you don't allow adult images (and you are able to filter them through your moderation system).It will also increase the security and credibility of your business, like the <a href="/two-step-verification/">Two-Factor Authentication</a> already added to pH7CMS.</li>
  <li>Bugfixed on some domain ports when forms were submitting.</li>
  <li>"imprint" page has been updated to "legal-notice" (and URLs as well).</li>
  <li>All assets have been compressed to make your dating website and social web apps more optimized and faster.</li>
  <li>Lot of minor improvements, messages, string, code comments, etc.</li>
  <li>Banned users are not visible anymore in public search results and homepage users block.</li>
<li>On iOS, by default the first letter is capitalized. To avoid wrong login for the users who don't write correctly the email in lowercase, the email field for the users &amp; affiliates login form is now case-insensitive.</li>
  <li>[For Programmers] Some code refactoring &amp; cleanups have been done.</li>
  <li>And other really nice surprises ;)</li>
</ul>
See you in the following days to say "HELLO" to pH7CMS 2.0

And by waiting, please really don't forget to <a href="/nominate-ph7cms-to-idate-awards/">nominate pH7CMS</a>!

This really helps indirectly the development and improvements of pH7CMS. So I count on you! :)

And thanks for your understanding ;)
