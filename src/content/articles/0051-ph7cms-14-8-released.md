Hi You! 👋

How are you doing today...? 🙂

In my case, I’m doing fantastic! 👌
Indeed, I've just released <strong>pH7 Social Dating CMS, 14.8.0</strong>!!! 🎉
<h2>What this new version offers? 🤔</h2>
<ul>
   <li>Added <strong>Schema.org markup</strong> (mainly on profile pages, blog and note posts). It will also <strong>improve your SEO</strong> 💪 (after the good work done in <a href="/social-seo-friendly-optimization/">pH7Builder, v14.7</a>.</li>
   <li>Allow through the admin dashboard to enable/disable the session IP check (that helps to prevent session cookies hijacking). Before v14.8, it was enabled by default, however it was causing issues if the client’s IP would frequently change.</li>
   <li>Allow to enable/disable "Google Maps" in one-click through the admin dashboard.</li>
   <li>Other improvements and code optimization.</li>
   <li>Minor bug fixes (e.g. with the <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/issues/370" rel="noopener noreferrer">"game" module</a> when adding a new game; Big thanks to <a href="https://github.com/developer1sirimarketing" rel="noopener noreferrer">@developer1sirimarketing</a> for having reported it).</li>
</ul>Hopefully, you will appreciate this new release.
