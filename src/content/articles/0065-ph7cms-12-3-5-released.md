Hi folks!

Hope you are still doing great! 🎉

Today, I'm very proud to announce another new release of <strong>pH7Builder (pH7CMS), v12.3.5</strong>.

This new version gives some fixes for <a href="/ph7cms-12-3-released/">pH7 Social Dating CMS, 12.3.0</a> release, several code improvements, better stability and improves <a href="/doc/">the documentation</a> as well! 🎉

More unit tests have been added. And the payment module won't allow you anymore to remove the default membership groups set in order to avoid nonexistent membership groups being used in the software.

Finally, several PHP third-party libraries have been updated to their latest versions 🥇

I hope you appreciate the <strong>hard work</strong> :)

See you soon ;) And good luck with your <strong>social dating web</strong> service 🍾🍹🎈
