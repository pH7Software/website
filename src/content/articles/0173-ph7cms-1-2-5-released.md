Hurra!! We just released <strong>pH7 Social Dating CMS 1.2.5</strong>!

This new release contained several minor bugfixes, browser and SSL issues, update of some third-party libraries (Colorbox, Mailcheck, Bootstrap, jQuery, ...).
The images in static and theme folders have been optimized thanks to <a href="https://imageoptim.com" rel="noopener noreferrer">ImageOptim</a>.

This version included also some minor improvements, such as <a href="http://daneden.github.io/animate.css/" rel="noopener noreferrer">Animate.css</a>, and others.

Finally, we have made some speed optimizations and fixed some bugs on the profile page, profile search results, dating splash page, game, note and blog pages caused by the new responsive template version on small screen resolution (such as iPhone and Android devices).

For current downloads and support, review the <a href="/get-started/">current pH7Builder options</a>.
This version doesn't require to update the database, so just overwrite the new files is enough :)

Otherwise, you can download the trial basic version on <a href="http://sourceforge.net/projects/ph7socialdating/" rel="noopener noreferrer">Sourceforge</a>.

Enjoy!! ;)
