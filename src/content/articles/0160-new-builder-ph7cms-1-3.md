Hi all!

I'm very happy today to announce the release of <strong>pH7CMS 1.3</strong>! Only three weeks after <a href="/ph7cms-1-2-9-release/">pH7CMS 1.2.9</a> :)

This new builder included many bugfixes, many improvements and  code refactoring (in order to keep the code better and always clean). New features have been added like the new "Social" template and the redesign of the "Dating" template that <a href="/new-social-dating-templates/">has been done one week ago</a> and the possibility to <a href="/ph7cms-ready-social-dating-niche/">choose a ready niche</a> during the installation implemented this week.

New splash background videos have been added and updated instead of the old one. Please also note if you hold <a href="/startup-kit-social-business/">pH7CMS Pro</a>, we can provide a specific professional background video that will suit with your current social/dating niche. Also, if you hold pH7CMSPro you will be able to upgrade your current version to this one and get the next updates.

 

pH7CMS 1.3 offers the possibility to change the environment mode to Development directly in your Admin Panel (this is very useful when you get "Internal Server Error" message).

 

Finally, pH7CMS 1.3 fully uses PHP 5.5 features. If you are still on a Web hosting supporting only PHP 5.4 as the highest version, please keep or use <a href="http://sourceforge.net/projects/ph7socialdating/files/1.2/pH7CMS-1.2.9.zip/download" rel="noopener noreferrer">pH7CMS 1.2.9</a> instead.

Hope you will enjoy this new version!

 

P.S. pH7CMS 1.3.0 is also a really special one because it is almost completely synchronized with its Gettext lang files (so easier for you to translate). The disadvantage of that those files are really big and makes the zip file much bigger than usual.
