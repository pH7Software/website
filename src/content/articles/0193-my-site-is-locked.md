Some sites has still an issue caused by the <a href="/all-our-apologies/">DDOS attack</a>.

The issue was displayed the following message:
<pre>You need to buy a valid pH7CMS License Key to use the features requiring a license key!</pre>
In order to resolve the problem, please remove the following folder:
<pre>/_protected/data/pH7_cache/str/</pre>
