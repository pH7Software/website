Hi guys!
I'm very happy to announce you today the new release for <strong>pH7 Social Dating CMS</strong>.

After weeks of developments, this version (1.3.8) is finally out and will give you again a much better stability for your social dating business.

<h4>More exactly, below is a summary of the change done:</h4>
<ul>
   <li>Better text color on the splash page</li>
   <li>Membership details page has been added to user account section</li>
   <li>Misspelling fixed</li>
   <li>Wrong "no_found" video path when no video was found</li>
   <li>Fake Generator Users use now the latest version of our profile provider (available only on <a href="/pro/">pH7CMS Pro</a>) and has several improvements and optimizations</li>
   <li>Several other bugs fixed</li>
</ul>

 

Hope you will enjoy this minor version and see you soon for the next big version that we are working on for months now! ;)
