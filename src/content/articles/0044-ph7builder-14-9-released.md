<strong>pH7 Social Dating Builder 14.9.0</strong> has just been released!!! 😻

This new version fixes a few bugs, code improvements and improves the readability of the code (again and again to make it always better), and fixes a <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/issues/415#issuecomment-453382373" rel="noopener noreferrer">bug caused by PHP 7.3</a> with the new <a href="https://wiki.php.net/rfc/pcre2-migration" rel="noopener noreferrer">PCRE2 version</a>.
So, you can now run pH7Builder on PHP 7.3 without any problems 🙂

Finally, it also fixes a "major" bug with the <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/tree/master/_protected/app/system/modules/mail" rel="noopener noreferrer">Mail module</a>. Users weren't able to see "sent" and "recently deleted (trash)" messages (a few improvements in the module have also been done).

You can see the full changelog here: <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/compare/14.8.9...14.9.0" rel="noopener noreferrer">https://github.com/pH7Software/pH7-Social-Dating-CMS/compare/14.8.9...14.9.0</a>
