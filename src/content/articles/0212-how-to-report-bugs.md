Currently, the best way to report bugs or issues about pH7CMS, it's to open a new issue to the <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/issues" rel="noopener noreferrer">pH7CMS's GitHub repot</a> and tell us with as much detail as possible the problem you encounter.
It will be very helpful for us if you can also attached a screenshot on the problem or a piece of code containing the bug (it depends on the problem).

<strong>Be careful!</strong> Before reporting any bugs or problems, please first set the <a href="/doc/en/how-to-set-the-development-mode/">environment mode of your site to "development"</a>, then go over to inspect the issue and then tell us.
