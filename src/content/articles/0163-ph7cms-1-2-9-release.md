Hi all!

Hope you are doing well ;)

pH7CMS 1.2.9 has just been released. This new version is mainly a maintenance version. It included a few of bugfixes and like the previous versions (<a href="/ph7cms-1-2-5-released/">pH7CMS 1.2.5</a> and <a href="/ph7cms-1-2-8-release/">pH7CMS 1.2.8</a>), pH7CMS 1.2.9 has also several bugfixes concerning the responsive design especially on small devices with the guest splash homepage.

Finally please note that this version doesn't included any change in the database, so you will just need to overwrite the new files to your site with a FTP client such as FileZilla.

Psst! Don't forget to make a backup of your site before to overwrite the files. We never know what can happen...

And if you have <a href="/order/">pH7CMS Pro</a>, you will be able to be assisted and helped with the professional support.

Hope you will like this new version! ;)

pH7CMS 1.2 branch is now very stable and mature (after several 1.2.* releases). The next version will probably be the new branch <b>pH7CMS 1.3</b>! :)
