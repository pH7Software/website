Hope you are still doing well today! :)

Anyway, I'm very happy for you today because I just released <strong>pH7CMS 6.0.8</strong>.

<h3>What's up in pH7CMS 6.0.8</h3>

<ul>
   <li>A few bugs fixed with the "payment" module for Stripe and Paypal payment gateways.</li>
      <li>Payment module has been improved. More details in the notification payment email have been added as well.</li>
        <li>"Browse Users" page was displaying the admin IP instead of the user IP. Now fixed.</li>
   <li>Improvement of the password algorithm and allows web developers to change the bcrypt work factor or hashing algorithm. It will automatically update the users' passwords without breaking any passwords.</li>
      <li>Better email permission reminder footer.</li>
      <li>Autocomplete users' details in contact form fields.</li>
      <li>Remove some unused files (clock feature that isn't used anymore).</li>
      <li>Improvements for the getProfileLink() feature.</li>
      <li>A few other minor improvements.</li>
</ul>
