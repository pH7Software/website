We are constantly pushing "pH7CMS social dating builder" to be more and more professional and useful in each new version.

Today, I noticed that pH7CMS doesn't allow to only display the profiles with profile photos (and approved) on the homepage.

Currently you can only set the number of profiles to be shown and if you want or not to display profiles on the homepage for visitors.

I'm now very happy to announce you that this is now from the past and from pH7CMS 7.0.13, you will be able to display profiles with ONLY profile photos.
