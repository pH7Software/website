Hi guys!

Today I'm again very happy to announce the new release of <strong>pH7CMS <em>dating site builder</em></strong>. pH7CMS 1.3.4 is the second version of the 1.3 branch and comes with several improvements!
<ul>
  <li>All forms and images are now fully mobile-friendly (responsive)</li>
  <li>Browse Users, Admins, Affiliates and Newsletter Subscribers got a better layout</li>
  <li>A better drop-down menu for small mobile screen resolutions has been added</li>
  <li>Improvement of the Like and Rating plugins</li>
  <li>The right headline on the homepage guest page can now be change through the Admin Panel -&gt; Settings -&gt; Meta tags (like homepage slogan and promo text)</li>
  <li>On the registration form, now user can directly upload an avatar on the last step</li>
  <li>Many bug fixed</li>
</ul>
 

This new version contains now only English for the default language of the site. The additional languages have been moved to a specific <a href="https://github.com/pH7Software/pH7-Internationalization" rel="noopener noreferrer">repo here</a>. However, the installation wizard still contains the additional languages. The reason is that it was useless to offer languages ​​to people who didn't need them by default.

Finally this version added a lot of new banner blocks (available on<a href="/startup-kit-social-business/"> pH7CMS Pro</a> only).

Hope you will love it and see you soon for other exiting news ;)
