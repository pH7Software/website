Hi all!

Hope everyone enjoyed the New Year's Eve.

Just after one week with the release of <a href="/ph7cms-1-2-7-released/">pH7CMS 1.2.7</a>. I'm very happy to announce the new release of pH7CMS, version 1.2.8 which fixed minor bugs, improvements added, better responsive on some forms and the <strong>possibility to enable/disable the system modules</strong>!
For example, if you want to use pH7CMS for a social networking service and not for a dating site, you can now disable the dating modules like "love calculator", "hotornot", "webcam", "chat", "chatroulette", "webcam" and "affiliate".
And the same if you want to create only a "Dating Site", you can now disable through the admin panel the Forum, Note, Blog, Video, Photo Albums and Game modules.

I'm sure this new feature will be very useful for you ;)

If you need help with a current release, review the <a href="/get-started/">current pH7Builder support options</a>.

Regards,

Pierre :)
