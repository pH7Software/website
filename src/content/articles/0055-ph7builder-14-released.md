Hi All! 😊

Today is a GREAT day! 🎉

Indeed, say H.E.L.L.O to the stable version of pH7Builder 14.0! 🍾 🍷

<strong>pH7 Social Dating Builder, v14</strong> is a brand new version with many improvements and changes (and many minor bugs have been fixed too)!

Along with several other improvements, a new <strong>date range option</strong> has been added on the user registration form.
Since pH7Builder v14, you can now choose between "date-picker" calendar or simple "age range" field in order to simplify the UX.
 New "Age Range" Field on the user registration form in order to simplify the registration.

 You can change the option through your admin panel -&gt; Settings -&gt; General -&gt; Registration

The API used for the "Fake Profile Generator" has also been <a href="https://github.com/pH7Software/pH7-Social-Dating-CMS/commit/8340c922ba84bad033e3fd04c7a0afc8ca65d886" rel="noopener noreferrer">updated to 1.2 version</a>. The Norwegian nationality has been added to the list of nationalities and a bug with the date of birth has been fixed.

pH7Builder's kernel has been optimized with better code practices, code quality (which makes it even faster!) and tends to use less CPU usage.

Finally, the new update is also fully compatible with the default settings of MySQL 5.7.5+

ALL the BEST with your Social Dating service 😍👑
