Hi everybody!

Today I wanted to explain you how to change the default chat on your site.

Indeed, as the chat in pH7CMS is an external service, it can't suit everybody.

You can change the chat by installing another chat on your Web hosting (e.g., <a href="http://www.phpfreechat.net" rel="noopener noreferrer">PHPFreeChat</a> which is free, available on <a href="https://www.softaculous.com/apps/others/phpFreeChat" rel="noopener noreferrer">Softaculous</a>, 123FlashChat, Flashcoms, ...) and then integrate the new chat by going to the API section in your Admin Panel, -&gt; Settings -&gt; API (and change the URL).

Finally, you can do the same with the Chatroulette.

Hope this will be useful!

Stay tuned!
