<p>Hi guys!<br>
Just to tell you that pH7CMS 1.1 is now available.<br>
This version includes many bug fixes, a new password hashing system, and some new features.</p>
<p>We also decided to delete the Donation plugin from the Page module as we find it unnecessary. If you really need it, you can still add it manually by adding the necessary code.</p>
<p>You can download it <a href="http://sourceforge.net/projects/ph7socialdating/files/latest/download" rel="noopener noreferrer">here</a>.<br>
The migration script for previous versions is also included in it.</p>
