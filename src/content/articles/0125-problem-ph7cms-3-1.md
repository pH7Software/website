There is a known issue with <a href="/ph7cms-3-1-released/">pH7CMS 3.1</a> if it's running on servers with PHP 5.6 and older.

In this case, please keep or install <a href="/ph7cms-3-released/">pH7CMS, version 3.0</a> or switch your PHP version to "7".

The problem will be fixed very soon in the next release, pH7CMS, version 3.2 / 4.0

Thanks for understanding ;)
