# pH7Builder website

The static Astro website for [pH7Builder](https://ph7builder.com), the
open-source foundation for independently owned dating, matchmaking and
community products.

## Development

```console
npm install
npm run dev
```

Before pushing:

```console
npm run build:ci
```

The production site is deployed to GitHub Pages from `main`. The complete
WordPress export is a local migration input and is intentionally ignored.
